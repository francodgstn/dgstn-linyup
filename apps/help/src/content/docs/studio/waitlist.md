:::caution[Experimental]
The waitlist is still experimental. It works, but it may change as we learn from the studios using it. If something doesn't behave as you expect, tell us at [hello@linyup.com](mailto:hello@linyup.com).
:::

When a class is full, people can join its waitlist. If a seat frees up, the next person in line is offered it for a limited time, and it moves on to the next person if they don't take it.
